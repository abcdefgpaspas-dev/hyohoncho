# 植物標本帖 (hyohoncho)

植物屋巡りと、育てている植物の記録をためる個人用アプリです。各ユーザーは自分専用のアカウントでログインし、自分のデータだけを見ることができます。

## セットアップ(初回のみ)

### 1. Supabaseにテーブルを作成する

1. https://supabase.com/dashboard/project/fkfgrhqzltjvcpxlouel を開く
2. 左メニューの **SQL Editor** を開く
3. このリポジトリの `supabase-schema.sql` の中身をすべて貼り付けて実行する
4. 左メニューの **Settings > API** を開き、**Project URL** と **anon public key** をコピーする
5. `config.js` の `anonKey` の値を、コピーしたanon keyに置き換える

### 2. メール確認の設定(お好みで)

Supabaseの **Authentication > Providers > Email** で「Confirm email」をオフにすると、友達がアカウント作成後すぐにログインできるようになります(オンのままだと確認メールのリンクを開く必要があります)。

### 3. GitHub Pagesで公開する

このリポジトリの **Settings > Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` に設定すると、数分後に公開URLが発行されます。

## 使い方

公開されたURLを植物友達に共有してください。それぞれが自分のメールアドレスでアカウントを作成すれば、各自の植物屋訪問記録・植物・予定・環境ログを個別に管理できます(他の人のデータは見えません)。

## 含まれる機能

- 植物屋の訪問記録、欲しい株のウィッシュリスト(購入したらワンクリックで植物一覧へ)
- 植物の登録(グループ分類: パキポカウレックス/アガベ/着生ラン/ビカクシダ/その他)と育成記録(水やり・植え替え・施肥など、潅水方法つき)
- ケアの予定管理(期限超過を赤字で警告)
- 気温・湿度・地温の環境ログとグラフ

AIによる写真自動判定・AI相談機能は、外部公開版では利用できません(Claudeアプリ内のArtifact版でのみ利用可能です)。
